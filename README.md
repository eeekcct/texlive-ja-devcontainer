# texlive-ja-devcontainer

このリポジトリは、TexLive を DevContainer で動かすためのサンプル設定を提供します．

## TeX Live の更新

Renovate が次の 2 種類の変更を確認し、TeX Live の更新 PR にまとめます．
更新 PR の作成は、月曜日の午前 3 時まで（日本時間）に制限しています．

- 年次リリース：CTAN の公開情報に基づく、Dockerfile の `TEXLIVE_YEAR` の更新
- 年内のパッケージ更新：配布元の `texlive.tlpdb.sha512` に基づく、`TEXLIVE_TLNET_SHA512` の更新

どちらの値もインストール処理で使うため、値が変わると TeX Live の Docker レイヤーを再構築します．
新しい定期実行ワークフローは追加せず、Renovate の PR を既存のビルドと PDF 比較で検証します．
試行中は TeX Live の更新を自動マージしません．PDF に差分が出た場合は、内容を確認してからマージします．

インストーラーは指定した年のアーカイブから取得します．
パッケージはビルド時点の tlnet から取得し、GnuPG による配布元の署名検証を有効にしています．
`TEXLIVE_TLNET_SHA512` は更新検知とキャッシュ更新用の目印であり、パッケージを固定するロックファイルではありません．
同じコミットでも再構築した日時によってパッケージが変わります．
完全な再現性が必要な場合は保存したイメージの digest または固定した配布リポジトリを使用してください．
年が切り替わった後に古い年の設定で再構築すると、配布元とのバージョン不一致で失敗することがあります．

ローカル環境への反映には、更新を取り込んでから Dev Container を再構築してください．
実行中のコンテナーの自動更新やイメージの公開は行いません．
